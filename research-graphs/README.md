# RH-06 — Research graph and data service

A dedicated worker will render trusted scientific graphs and data-backed figures from typed input specifications. Approved output may include SVG, PNG and CSV with units, input hashes, renderer versions, observational/model classification, source attribution, limitations and revision history.

This service is **not implemented or deployed** in RH-01. The /relationships endpoint is a structural representation of public area/article links, not a scientific causal graph.
