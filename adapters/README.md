# RH-07 — Sustainable Catalyst adapters

Read-only integration targets: Knowledge Library and Research Librarian, Workspace/Reporting Studio, Workbench graphs, Research Lab datasets and notebooks, Site Intelligence imagery, Decision Studio analytical objects, and Publications.

No adapter is enabled in the RH-01 foundation. Each must verify live API contracts, object ownership, source version, rights, freshness, hashes, and public-display approval. Do not directly access another service's database or change its runtime.
