# Public Research source boundary

This repository is a source-only build of the Sustainable Catalyst Research application. It deliberately contains **no prior private Git history** or private Research/Workspace records.

Included: FastAPI code, versioned migrations, public metadata/graph logic, disabled-by-default discovery and WordPress adapters, generic development Compose, source contracts, synthetic tests, and GitHub CI for standard runners.

Excluded: internal deployment/staging Compose files, operator scripts, environment-specific release gates, production image publication workflows, real-world acceptance receipts, confidential handoffs, tenant/owner datasets, personal research documents, and tests that require the excluded private operations. These remain in private operational repositories.

Public source does **not** imply a production deployment, live Workspace identity, approved scientific article, permission to redistribute third-party works, or a software license. Enabling any private/production capability requires its own authorization and acceptance tests.

If an operational problem is discovered, report it privately to the repository owner. Never post credentials or private customer/research data in public issues.
